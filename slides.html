What is it

這個 SDK 是什麼

  • 內建 agent 迴圈讀檔、跑指令、搜尋、改程式碼，開箱即用
  • 對比 Client SDK那邊你自己寫工具迴圈；這邊 Claude 幫你做掉
  • 同一套 Claude Code 核心工具、上下文管理、權限全都在

async for message in query(

    print(message)   # 讀檔、找 bug、改檔，全自動

query()

Hello World

整個 SDK 最基礎的形狀：送 prompt → 迭代訊息流 → 挑出要的。

  • query() 回傳訊息流不是一句字串，而是一串可 async 迭代的訊息
  • 認出 AssistantMessage走訪 content，挑 TextBlock 拿文字
  • ResultMessage 收尾最後一則，帶成本與回合數
別期待 query() 直接給字串——文字藏在 AssistantMessage 的 TextBlock 裡。

Message stream

訊息型別

一個會用工具的 agent，吐出的是一齣有來有回的戲。

  • SystemMessage(init)開場：session_id、可用工具、模型
  • AssistantMessageClaude 發言：TextBlock 或 ToolUseBlock
